# 会话唤醒（dsh-wake）

后台跑一个脚本。脚本往 stdout 打出一行标记时，把这一行投进发起会话，并开一轮。会话正忙时排队，不丢。

默认标记行：

```text
DSH_WAKE: 3 个 MR 已全部合并，可以创建发版分支
```

Agent 调用：

```text
wake_run({
  argv: ["node", "watch.mjs"],
  label: "等 MR 合并"
})
```

调完就可以结束本轮。脚本必须由 `wake_run` 启动；用户自己在终端里跑的进程不会唤醒会话。

- 只匹配 stdout。stderr 不触发。
- 同一任务 1 秒内的多行只投递最后一行。
- 非 0 退出会再唤醒一次，带上退出码和 stderr 尾部。
- 0 退出且从没打出标记行，也唤醒一次，避免会话一直以为还在监听。
- `wake_stop` 只终止进程，不唤醒。
- DSH 重启后不会自动重拉脚本。
